# Boltay

Голосовой ввод для русского и английского, который работает прямо на твоём компьютере. Зажал хоткей, сказал, отпустил — текст уже там, где стоит курсор: с запятыми, без «эээ» и «короче». Ничего из сказанного никуда не уходит.

[English](README.md)

## Что умеет

- **Русская и английская речь.** Русский распознаёт [GigaAM v3](https://github.com/salute-developers/GigaAM), английский — [Parakeet](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3). Десять секунд речи — меньше секунды на обычном процессоре. Видеокарта и аккаунт не нужны. В сеть приложение ходит только за моделями и раз в день проверить новую версию, это можно выключить.
- **Текст, который не надо править.** «Ну», «короче», «типа» вычищаются. Пунктуацию можно говорить словами: «запятая», «вопросительный знак», «новая строка», «абзац», «удали последнее». Названия пишутся как надо — GitHub, а не «гитхаб». Мат оставить, замаскировать, вырезать или смягчить — как скажешь. Сверху свои замены и заготовки.
- **Говоришь по-русски — вставляется по-английски.** Второй хоткей диктует по-русски и вставляет перевод.
- **Переводчик по выделению.** Выделил текст где угодно, нажал хоткей — рядом плашка с переводом с русского на английский или обратно, сленг и сокращения расшифрованы. Скопировать или вставить вместо выделенного.
- **Голосовые и записи в текст.** Кинь файл на окно: голосовые из Telegram (ogg/opus), mp3, m4a, wav, flac — до четырёх часов.
- **История** надиктованного, если нужна: хранится у тебя и чистится по сроку.

## Скачать

В [релизах](https://github.com/relaxcorp/boltay/releases/latest):

| Система | Файл | Первый запуск |
| --- | --- | --- |
| Windows 10/11 | `Boltay_*_x64-setup.exe` | SmartScreen может ругнуться на неизвестного издателя: «Подробнее» → «Выполнить в любом случае». |
| macOS 13.4+, Apple Silicon | `Boltay_*_aarch64.dmg` | Перетащи Boltay в «Программы» и запускай оттуда. С первого раза macOS не даст: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть». Потом разреши микрофон и Универсальный доступ — приложение само попросит. |
| Linux x64 | `Boltay_*_amd64.AppImage` или `.deb` | Собрано на Ubuntu 22.04, работает на ней и новее. |

При первом запуске Boltay качает модель речи: 216 МБ для русского, 639 МБ для английского. Модели перевода — при первом переводе: около 110 МБ на направление, качественные — около 560 МБ.

Маки на Intel не поддерживаются: под них больше не выпускают ONNX Runtime, на котором работают модели.

## Хоткеи

| | Windows | macOS, Linux |
| --- | --- | --- |
| Диктовка | Ctrl+Shift+Space | Ctrl+Shift+Space |
| Диктовка с переводом на английский | Ctrl+Shift+Alt+Space | Ctrl+Shift+Alt+Space |
| Переводчик | Ctrl+Alt+T | Ctrl+Shift+Alt+T |

Держишь — говоришь, или в настройках переключи на «нажал — начал». С включённой защёлкой двойное нажатие пишет без рук до следующего нажатия. Esc отменяет. На Windows можно и одной клавишей: правый Ctrl, правый Alt, правый Shift или CapsLock.

**Wayland:** глобальные хоткеи срабатывают, только когда в фокусе X11-приложение. Назначь в системе сочетание на `boltay-app --dictate` (или `--translate`, `--translator`) — каждое нажатие запускает или останавливает. Для вставки там нужен `wtype` или `ydotool`, без них Boltay покажет текст с кнопкой «Скопировать».

## Сборка

Нужны Rust (stable), Node 22 и на Linux пакеты из `scripts/linux-deps.sh`.

```sh
./scripts/fetch-models.sh                  # модели для тестов, в ./models
cargo test --workspace
cd app && npm ci && npx tauri build
```

`cargo run -p boltay-cli -- transcribe file.wav --models models` распознаёт из командной строки, `translate "текст" --models models` переводит.
